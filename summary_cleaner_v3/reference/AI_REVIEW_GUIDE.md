# 训练数据 AI 审核指南（buckets_v2）

你正在审核「序时账业务分类」训练数据。数据按桶聚合组织，你的任务是：
**一个桶一个桶看，发现不属于该桶的记录，直接从桶里删除。**

## 文件格式

```json
{
  "fingerprint": "哈希", "reviewed": false,
  "buckets": {
    "存货采购": [
      {
        "subjects": ["应付账款[借]", "银行存款[贷]"],   ← 科目组合（借/贷）
        "records": [
          {"summary": "付杭州分公司货款", "count": 3, "confidence": "high"},
          {"summary": "付北京分公司货款", "count": 5, "confidence": "low"}
        ]
      }
    ]
  }
}
```

- **buckets** = 按桶聚合。每个桶下是一组「科目组合节点」
- **subjects** = 该组合的科目+方向（如 应付账款[借]、银行存款[贷]）——业务结构线索
- **records** = 该科目组合下的摘要列表（整句，最重要线索），count = 出现次数（高频更该审准）
- **confidence** = 置信度标记（可选）：high = 与金标准一致不用细看；low = 重点审

## 置信度拆分（重要）

置信度比对程序会把与已审核金标准高度一致的记录
（同科目组合 + 同桶 + 摘要相似度≥75%）**自动并入金标准 training_data.json**，
**你不需要看它们**，也不会读入你的上下文。

主文件（未审目录中的 `{hash}.json`）仅剩低置信度记录，
**你审核的就是这份**。记录带 `confidence: "low"` 标记（或无标记，按常规审核）。

## 审核规则（核心）

1. 一次看一个桶。对照下方桶定义，判断桶下每个「科目组合 + 摘要」是否真的属于该桶
2. **不属于该桶** → 直接删除：
   - 整个科目组合节点都不对 → 删除该组合节点（连同其 records）
   - 组合对但个别摘要不对（如混入其他业务）→ 删除该摘要节点
3. **拿不准 → 删除**（训练数据宁缺毋滥，只留下最明确、稳健的样本。
   存疑样本会教坏模型，宁可少一点数据）
4. **只删不改**：不要修改桶名，不要新增记录，不要移动记录到别的桶
   - 删除是唯一操作。保留的都是你确认正确的样本
5. 审完把该文件的 reviewed 改为 true
6. 保留其他所有字段与结构

### C. 备注
- 拿不准 → 删除（宁缺毋滥）
- 日期 / 凭证号 / 金额 / 票号对分类无意义，忽略
- 同一科目组合可能对应多个节点（如同一 subjects 出现两次），逐节点处理
- 审核后必须做残留扫描：银承付 / 往来款 / 员工借款 / MES 开发费 / 结转进项税 等关键词应只在预期桶出现，残留需逐条甄别是漏删还是正确保留

# 序时账清洗 · 复核口径

**这个功能在做什么**：给每张凭证判一个「业务桶」，判完写回原表，产出「业务分类结果」。
模型已经全部判过一遍并给了置信度；**你只看它拿不准的**（中/低置信）和与硬规则冲突的。
你的改判会按「同模板组内连带」扩散到同类凭证，所以判对模板比判对单张更值钱。

## 怎么判（顺序不要倒）

1. **先看整张凭证的分录**。货币资金/往来那一侧只说明钱怎么走，**对方科目说明这笔钱是干什么的**——
   判桶看后者。只给一行「银行存款 借 32,000」你判不出桶，给「银行存款 借 / 应付账款 贷」就判得出。
2. 再看摘要里的业务名词（货款、工资、加工费、利息、手续费…）。摘要只做提示，不能单独定桶。
3. 最后才参考模型给的桶和概率。模型 Top3 贴身（差 < 0.05）时，多半是它没读懂摘要，别按分数高低选。
4. 金额为 0、科目为空、凭证号像「1900年1月-号」的，是解析残渣，按「其他经营收支」放，别硬塞业务桶。

## 桶的边界（最容易混的几对）

- **生产制造**只收"物料的转化"：领料投产、完工入库、委外加工收发、制造费用结转生产成本。
  车间发生的水电/办公/劳保按性质归「费用」，车间工资归「薪酬」，车间设备折旧归「折旧摊销」。
- **成本结转**收"商品卖出去"：库存商品→主营业务成本、发出商品。领料投产不是它。
- **采购** vs **长期资产购建**：买进仓的存货/辅料是采购；买设备、模具、场地搭建并资本化的是长期资产购建。
- **研发**：借「研发支出」的（出库领料、测试样品、流片、光刻板、委外研发入库），不管摘要写"出库/样品"都归研发；
  但「结转本期研发费用」（管理费用 借 / 研发支出 贷）归费用，不追研发，否则研发桶虚高。
- **同一笔业务的预付和发票入账必须同桶**：预付流片费→研发，之后收到发票冲预付也是研发；
  供应商退预付/退款冲「预付账款」→ 采购；客户退款冲「应收账款」→ 销售。看冲的是哪个科目，比看"退款"二字可靠。
- **财务费用**下面：银行/代发手续费→结算手续费；期末汇率调整→汇兑损益；纯重分类（财务费用↔投资收益）→投资。

## 硬规则（程序直接定，不问你）

汇兑损益、资金内部往来、期末结转、员工借支这几类由科目组合直接判定。它们如果出现在待办里，
说明同时命中了别的理由——按「为什么要看」那一列判断，别无视它。

## 交付

改判写 decisions：`key`=凭证号，`value`=桶名（只能用待办给的可选值），`note`=一句依据。
判完程序会写回原表并导出，产物在任务的 `out/export/`。

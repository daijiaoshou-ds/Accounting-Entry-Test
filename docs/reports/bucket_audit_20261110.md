## 三、三类问题，三种解法

### ① 父子互串（已解决）

`费用 ↔ 费用·办公` 曾占全部错误 18.6%。合并费用子桶后消失，不再讨论。

### ② 摘要依赖型（组合学不会，**不要补组合样本**）

| 桶 | 组合准确率 | 本质 |
|---|---:|---|
| 结算手续费 / 押金保证金 / 筹资费用 / 存款利息 / 单位往来 / 员工借支 | 0% | 科目组合与邻近桶**完全一样**，业务性质只在摘要里 |
| 研发 / 费用 | 11.0% / 12.6% | 同上，但真实摘要从不会空 |

典型：`财务费用[借] + 银行存款[贷]` 既可能是**结算手续费**（账户管理费），也可能是
**利息支出**（付利息）。科目组合无法区分，只能靠摘要措辞。这类桶的正确目标不是
"学会组合"，而是**措辞泛化**（A 组），补样本时要补**新说法**，不是补新组合。

### ③ 真·样本不足 + 边界模糊（该补样本）

| 桶 | 常规 | 记录数 | 问题 |
|---|---:|---:|---|
| 结算手续费 | 72.0% | 221 | 与利息支出/费用 边界靠词，且"管理费"易被判成费用 |
| 投资 | 78.7% | 100 | 样本少；错向「薪酬」12 条疑似误标（代扣个税） |
| 长期资产处置 | 80.0% | 93 | 验证只有 20 条，统计意义弱 |
| 长期资产购建 | 81.0% | 1,308 | 与「政府补助/费用/折旧摊销」边界；进项税+预付款场景多 |
| 借款 | 85.7% | 155 | 还本付息 vs 利息支出，标签口径不一 |
| 税费 | 88.0% | 486 | 缴税 vs 采购带进项税，摘要像采购 |
| 折旧摊销 | 89.0% | 117 | 与费用（计提折旧进管理费用）边界 |

## 四、高置信分歧 = 疑似误标（**补样本之前先看这个**）

模型置信 ≥0.90 却与金标准不一致的样本共 **242 条**：
`_dev/bench/raw/label_suspects_20261110.json`（含摘要/科目/金标准/模型结论/置信度）。

| 真实 → 预测 | 条数 | 读法 |
|---|---:|---|
| 结算手续费 → 利息支出 | 20 | 都是财务费用，摘要没说清；口径需定义 |
| 长期资产购建 → 政府补助 | 20 | 多为"收到补贴/拨款"，标签可能错 |
| 长期资产购建 → 费用 | 19 | 发票/预付款场景，是否资本化需判断 |
| 结算手续费 → 费用 | 16 | "账户管理费"被判费用，边界问题 |
| 生产制造 → 采购 | 14 | 领料 vs 采购入库 |
| 长期资产购建 → 折旧摊销 | 13 | 计提折旧被标进购建 |
| 投资 → 薪酬 | 12 | "代扣代缴个税"，标签大概率错 |
| 采购 → 费用 | 11 | 费用化 vs 资本化 |

**结论：先复核这 242 条，再补样本。** 不然补进去的样本会复制同样的错误口径。

## 五、补样本规格（给生成样本的 AI）

原则：**补对抗样本，不补同义改写**。每条样本 = 摘要 + 科目组合 + 正确桶，
且要"看起来像邻近桶、实际属于目标桶"。

| 目标桶 | 建议新增 | 必须覆盖的形态 |
|---|---:|---|
| 结算手续费 | 200 | 账户管理费/网银年费/跨行手续费/结售汇手续费（vs 利息支出：付息、罚息、贴现息） |
| 长期资产购建 | 300 | 设备预付+进项税、在建工程领料、安装调试费、资本化利息（vs 费用：日常维修） |
| 税费 | 200 | 增值税缴纳、附加税、印花税、代扣代缴（vs 采购：发票含进项但实质是采购付款） |
| 投资 | 150 | 股权投资付款、收到分红、理财申购赎回、权益法确认（vs 薪酬：代扣个税） |
| 长期资产处置 | 120 | 固定资产清理、报废残值、处置损益（vs 销售：卖产品） |
| 借款 | 120 | 提款、还本、付息、罚息（vs 利息支出：只付息不还本） |
| 押金保证金 | 100 | 收/退保证金、押金、投标保证金（vs 单位往来） |
| 折旧摊销 | 100 | 计提折旧（管理费用/制造费用）、无形资产摊销（vs 费用） |
| **合计** | **≈1,290** | |

每条都要带"邻桶对照"：同一摘要改一个词就能变成邻桶，让模型学会分辨关键词。
